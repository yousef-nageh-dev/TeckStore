# 🛒 TeckStore / SuperMarket Console Application

A robust **C# Console Application** built to manage store inventory, product data, and sales operations. Designed with Object-Oriented Programming (OOP) principles and efficient data structures.

---

## 📝 About The Project
This project is an automated store management system that allows administrators and users to handle daily supermarket/store management tasks cleanly through a command-line interface.

## 🛠️ Tech Stack & Concepts
* **Language:** C# (.NET)
* **Architecture:** Object-Oriented Programming (OOP)
* **Concepts Applied:** Encapsulation, Classes & Objects, Collections, Data Processing
* **IDE & Tools:** Visual Studio / VS Code, Git & GitHub

## 🚀 Key Features
* 📦 **Product Management:** Add, update, view, and delete products in inventory.
* 🛍️ **Manager / Sales Flow:** Process orders and handle inventory counts efficiently.
* 🔒 **Data Validation:** Input verification for clean console interaction.
